Enforcer Plugins
The inbound sidecar calls all enforcers before the agent sees the request — fail-closed, any can deny

OPA

Policy rules evaluated locally against trust context.

  • Input: trust headers, agent card, request metadata
  • Deny if no principal in chain
  • Deny if target not in declared dependencies
  • Deny if caller not in allowed callers
  • Allow if no deny rules triggered

Trust Score Engine

Real-time risk scoring from lineage baseline + external evals.

  • Novel edge: agent calling a new target
  • Novel resource: first-time access
  • Depth exceeded: chain deeper than threshold
  • Fanout exceeded: too many delegations
  • Retry storm: repeated calls, short window
  • Capability overreach: undeclared dependency
  • Agent evals: quality, safety, hallucination

External PDP(s)

Any policy engine via standard authz callout protocol.

  • Input: same trust context (headers, card, metadata)
  • Output: allow / deny
  • Protocol: gRPC or HTTP
  • Pluggable: connect to any number of PDPs
  • Composable: external trust frameworks plug in here

Trust Header Propagation
How headers transform hop by hop — principal and run_id are immutable, caller and hop_kind mutate
Hop x-principal-id x-caller-id x-caller-type x-request-id x-trust-hop-kind Span emitted
Ingress → chat-agent user:alice user:alice principal run-7a3b ingress alice → chat-agent
chat-agent → sales-agent user:alice agent:chat-agent agent run-7a3b delegation chat → sales
sales-agent → mock-database user:alice agent:sales-agent agent run-7a3b resource_access sales → database

Immutable (set once at ingress)

x-principal-id — the verified identity of the original caller. Carried unchanged through every hop so any point in the chain can answer: who started this?

x-request-id — correlation ID for the entire delegation run. Every span in the chain shares this as trust.run_id.

Mutable (updated at each outbound hop)

x-caller-id — updated by each outbound sidecar to the current agent's identity.

x-caller-type — principal at ingress, agent after first hop.

x-trust-hop-kind — ingress → delegation → resource_access.
